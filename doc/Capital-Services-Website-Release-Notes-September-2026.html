Release Notes

Capital Services Website

Premium case studies, coverage map basemap & site polish

Version: 1.3.0  |  Release date: 5 September 2026

Prepared for: Capital Services Ltd

Repository: alphah-dev/capital_services_draft

Environment: Vite static site — deployed via Vercel

Executive Summary

Release 1.3.0 delivers six full illustrative case study pages with real Cloudinary before/after imagery and an upgraded drag comparison slider, locks the coverage maps to an Esri Satellite basemap with brand amber overlays, and removes unfinished demo placeholders from Testimonials. Clients and Home “View Case Study” links now land on dedicated, production-quality story pages.

Release Highlights

  • Six premium case study pages: Water, Fire, Storm, Subsidence, Commercial, and Major Loss.
  • Real before/after Cloudinary pairs on every page — no CSS-filtered duplicate images.
  • Interactive drag slider with scroll-in hint wipe, clearer handle, and keyboard support.
  • Full-bleed hero, challenge/approach storytelling, six-phase timeline, key data, testimonial, CTA, and related cases.
  • Coverage and office maps use Esri World Imagery; colour-preview demo UI removed.
  • Placeholder “Client Stories” video cards removed from Testimonials.
  • Coverage map status text letter-spacing corrected for readability.

New Features

Premium Case Study Pages

Each peril now has a dedicated page registered in the Vite multi-page build and linked from Clients (all six) and Home (Water, Storm, Commercial). Shared styles and scripts live in css/pages/case-study.css and js/pages/case-study.js.

Page structure on every case study:

  • Full-bleed hero — scene photography, category badge, title, subtitle, animated claim / duration / trades counters.
  • Challenge / Approach — two-column project storytelling.
  • Before & After slider — real photographs with drag, touch, arrow-key control, and a one-time auto-hint wipe on scroll-in.
  • Project timeline — six concrete phases with scroll-fill progress.
  • Key data — insurer, location, property type, value, duration, lead.
  • Testimonial, CTA, and related case cards — cross-linked among the six stories.

Copy is demo-realistic (UK locations, plausible claim values, illustrative insurer names) and matches the tone of the existing marketing site. A cinematic hover reveal was evaluated and intentionally omitted so each page keeps a single, clearer before/after interaction.

Technical Notes

Stack & hosting

  • Frontend: Static HTML, CSS, JavaScript — Vite 6 multi-page build.
  • Maps: Leaflet + Esri World Imagery tiles via map-tiles.js.
  • CDN: Cloudinary (foxrj3tm) for case study before/after assets.
  • Hosting: Vercel — build command npm run build, output dist/.

Case study scripts

  • Animated hero counters on scroll-in.
  • Before/after slider with drag, touch, keyboard, and optional auto-hint wipe.
  • Timeline scroll-fill with active phase highlighting.

Environment variables (Vercel)

No new environment variables are required for this release. Cloudinary delivery URLs are baked into HTML. Team portal variables from 1.2.0 remain unchanged.

Accessibility & Performance

  • prefers-reduced-motion honoured on hero counters, slider hint, and timeline transitions.
  • Lazy loading on case study gallery and related-card imagery.
  • Case study media served via Cloudinary f_auto,q_auto with width constraints.

Known Considerations

  • Case study narratives are illustrative for the demo website — confirm wording before treating them as public case references.
  • Esri imagery attribution is provided by Leaflet; satellite tiles are subject to Esri’s public tile terms of use.
  • Local high-resolution “after” source PNGs are not committed to Git (already on Cloudinary).
