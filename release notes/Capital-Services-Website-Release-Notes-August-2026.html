Executive Summary

Release 1.2.0 strengthens the Capital Services demo website with an interactive Before → After animation on Insurance Peril cards, a full migration of site imagery to the Cloudinary CDN, refreshed Team Leads content on the About page, and operational improvements to the internal team portal. The release is production-ready on Vercel and maintains the brand positioning established in version 1.1.0.

Release Highlights

  • Interactive peril card animation on Home and Services — damaged property transitions to restored outcome on hover (touch-supported).
  • Six AI-generated “after restoration” images hosted on Cloudinary under structured public IDs.
  • Full media CDN migration to Cloudinary account foxrj3tm with automated upload and apply scripts.
  • About page Team Leads redesigned with flip-card profiles, professional bios, and fixed LinkedIn actions.
  • Team portal routes (/team, /crew, /admin, /survey) corrected for Vercel deployment.
  • Survey persistence fix for PostgreSQL JSON handling on the operations API.
  • Responsive layout refinements for laptop, tablet, and mobile viewports.

New Features

Insurance Perils — Before / After Hover Animation

Each of the six peril cards (Escape of Water, Flood Damage, Fire & Smoke, Subsidence, Impact Damage, Storm Damage) now presents a three-phase interaction:

  • Before state — Damaged property photograph with a red “Before” badge.
  • Restoration overlay — Branded Capital Services logo, “Restoring your property…” messaging with animated progress indicator.
  • After reveal — Circular clip-path transition revealing the restored property image with a green “✓ Restored” badge.

The animation reverses smoothly on mouse leave. On touch devices, the first tap triggers the sequence; a second tap resets the card. Users who prefer reduced motion receive a simplified, non-animated presentation.

Cloudinary Media Delivery

Site assets previously served from local assets/ paths or legacy CDN accounts have been consolidated on Cloudinary. Delivery URLs include automatic format and quality optimisation (f_auto,q_auto). Restoration “after” images are capped at 1200px width for faster page loads.

Technical Notes

Stack & hosting

  • Frontend: Static HTML, CSS, JavaScript — Vite 6 build.
  • Animation: Pure CSS transitions and vanilla JavaScript (no third-party animation libraries).
  • CDN: Cloudinary (foxrj3tm) — 82 assets catalogued in data/cloudinary-manifest.json.
  • Hosting: Vercel — build command npm run build, output dist/.

Developer scripts

  • npm run cloudinary:upload — Upload local assets to Cloudinary and refresh manifest.
  • npm run cloudinary:apply — Replace local asset paths in HTML, CSS, and JS with CDN delivery URLs.

Accessibility & Performance

  • prefers-reduced-motion honoured on peril card animations and flip-card interactions.
  • Lazy loading applied to non-critical imagery.
  • GPU-accelerated clip-path used for peril reveal transitions.
  • After-restoration images delivered via Cloudinary with automatic compression and format selection.

Known Considerations

  • Team lead bios are summarised from publicly available professional information and should be reviewed by HR or leadership before a public go-live.
  • Stephanie Baxter does not currently have a verified LinkedIn profile linked on the site.
  • Cloudinary credentials belong in local .env only — never commit secrets to the repository.
  • Original high-resolution “after” PNGs remain available locally for re-upload if further compression is desired.
